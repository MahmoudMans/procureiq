# ProcureIQ: Procurement Intelligence Platform

> **To fill in before publishing:** your role, the timeline, a link to the repository and a link to a live demo.

## Overview

ProcureIQ is a full-stack procurement platform. A purchase request is approved, turned into a request for quotation (RFQ), quoted by suppliers through their own portal, evaluated and awarded, and then becomes a purchase order that the supplier acknowledges or rejects. Goods are received against the order and supplier delivery performance is tracked.

## Engineering practices

- State changes are guarded in the SQL itself, so they stay correct under concurrent use. For example, a purchase order can be answered by the supplier only once, and cannot be reopened after goods have been received.
- Supplier access is isolated in the API and covered by tests: one supplier cannot see another's quotations or orders, and an unsuccessful bidder is never told who won.
- Tests come in layers: unit tests, PostgreSQL integration tests that each run in a disposable schema, end-to-end API smoke tests, a checker that prepares every repository query against the live database, and a browser test that drives the screens in Chrome.
